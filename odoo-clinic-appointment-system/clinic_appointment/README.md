# Odoo Doctor Appointment Module

A custom Odoo module designed to streamline the booking and management of doctor appointments. 

## Key Features

1. **Customer Booking (No Login Required):** Allows customers to book appointments directly without needing an account. 
2. **Employee Booking (Login Required):** Employees can log in to the system to book appointments on behalf of patients.
3. **Doctor Specialization Filter:** Displays a list of doctors categorized by their medical specialization.
4. **Availability Tracking:** Displays the available times for each doctor to prevent scheduling conflicts.
5. **Automated Follow-ups:** Employees must follow up on customer appointments 1 to 2 weeks after treatment via an activity prompt.
6. **Customer Details Collection:** The booking form captures essential patient information, including name, birthdate, age, email, and phone number.
